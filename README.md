One joke about office life, one line, under 200 characters — written by `main.py` to `/output/entry.txt`.

> The office printer never jams on junk mail — it waits for the one urgent document, then eats it like it's up for promotion.

## What the joke does

Every office worker knows the printer's timing: it never chokes on the junk, only on the one document that actually matters. The turn lands in the last words — the printer isn't broken, it's ambitious, eating your urgent work like it's up for promotion. True to the office, surprising at the end, tight enough to read aloud in one breath.

## How to run

```sh
python3 main.py
```

This validates the line (single line, 1–200 UTF-8 characters, not only whitespace) and writes it to `/output/entry.txt` with no trailing newline.
